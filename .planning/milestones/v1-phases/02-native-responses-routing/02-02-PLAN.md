## Trust Boundaries
| Boundary | Description |
|---|---|
| Client -> gateway headers | Credentials, cookies, and hop-by-hop metadata are attacker-controlled |
| Gateway -> provider auth | Gateway chooses credential flavor and upstream URL |
| Upstream stream -> client | Status/body bytes become observable and establish replay boundary |
