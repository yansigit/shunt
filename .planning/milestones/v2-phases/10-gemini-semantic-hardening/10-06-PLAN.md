<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Anthropic tool history → Gemini request | Client-carried IDs select which provider call receives each result. |
| Gemini Part JSON → Anthropic output | Provider-controlled Part keys determine whether semantics are represented, ignored, or rejected. |
| Upstream SSE bytes → terminal state | Provider bytes after a framing terminal can incorrectly authorize deferred success. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-G06-01 | Tampering | parallel tool-result matcher | high | mitigate | Require a complete one-to-one ID mapping before emitting any result and preserve stored call order. |
| T-10-G06-02 | Spoofing | foreign or duplicate tool ID | medium | mitigate | Reject IDs absent from the one outstanding batch and reject duplicate consumption atomically. |
| T-10-G06-03 | Tampering | Gemini Part classifier | high | mitigate | Enumerate known semantic keys and reject unsupported or incompatible combinations before state mutation. |
| T-10-G06-04 | Denial of Service | result-batch lookup | low | accept | Existing bounded message/tool state makes a linear per-batch identity lookup tolerable and deterministic. |
| T-10-G06-05 | Tampering | post-DONE SSE handling | high | mitigate | Reject every completed frame at the decoder boundary before no-op parsing and test arbitrary packetization. |
</threat_model>
